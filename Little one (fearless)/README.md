# Hi Little One — Simple Web App

This is a tiny, static web app meant for a young child. It shows a friendly greeting and a button — when clicked it displays a GIF and the message *Be fearless.*

How to use
- The app now includes a built-in, free animated SVG at `assets/powerup.svg` so no external GIF is required. If you prefer a GIF, replace `assets/powerup.svg` with `assets/powerup.gif`.
- Open `index.html` in a browser (double-click or use a local static server).

Notes
- I left the GIF as a local asset so you can pick any image you prefer (for example a female Super Saiyan powering up). If you want, I can help locate a suitable GIF online or embed one directly.

Fan-art buttons
- The buttons are labeled by color (Red, Yellow, Blue, Green). Click a button to show a local image for that color in the modal.

Credits and hosting
- Add image files to `assets/` named `red.png`, `yellow.png`, `blue.png`, and `green.png`.
- In `script.js` the `gallery` object contains `credit` and `link` fields; update those with the artist's name and page.
- If you provide the artist's images and permission, I will embed them and include credit lines under the image.

Copyright note
- Respect the artist's copyright: only add images you have permission to host locally. The default app uses an original `assets/powerup.svg` that is free to use.
