# Pathfinder Resource Hub

A frontend web application designed to help students quickly access university resources, career tools, and internship opportunities through an organized and responsive interface.

---

## Features

- College-specific resource tabs
- Organized student resources
- Responsive frontend design
- Expandable UI structure
- Quick navigation system

---

## Built With

- React
- Vite
- JavaScript
- CSS

---

## Purpose

This project was built to strengthen my frontend development skills while creating a useful resource platform for students and early professionals.

---

## Future Improvements

- Search functionality
- User accounts
- Saved resources
- Backend/database integration
