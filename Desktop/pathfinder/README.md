# PathFinder Resource Hub

PathFinder is a frontend resource platform designed to help students and young adults discover scholarships, financial aid, career preparation tools, trade opportunities, and Maryland college support resources in one place.

## Purpose

Many students are not lazy — they are overwhelmed and unsure where to begin.

PathFinder was built to simplify access to educational and career resources through a clean and accessible user experience.

## Features

* Scholarship resource links
* FAFSA and financial aid guidance
* Trade and apprenticeship resources
* Resume and LinkedIn support
* Maryland college resource tabs
* Search functionality
* Category filtering
* Responsive frontend design
